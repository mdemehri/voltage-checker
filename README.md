# Voltage Checker

A small Python tool that reads board voltage measurements from a CSV file
and marks each reading PASS, FAIL, MISSING, or INVALID against a 4.75-5.25 V range.

- check.py: the checker (run with: python check.py)
- test_check.py: unit tests (run with: python -m unittest -v)
- readings.csv: sample data (made up)

Built as a learning project using AI-assisted development (Claude). I reviewed
and tested all code and fixed bugs found during testing, including missing values.
